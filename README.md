# Corpus Linguistics - Study 1 - GELC LLM Taggers

## Phase 1 - Tagset testing

### Acesso aos tagsets para revisão

Para que os grupos possam realizar testes e ajustes nos tagsets, é necessário baixar o repositório no computador pessoal.

Para o manuseio de documentos, recomendamos instalar e usar o editor de código Visual Studio Code (https://code.visualstudio.com/), também conhecido como VS Code. Instale nele a extensão `Markdown All in One` usando o procedimento https://code.visualstudio.com/docs/configure/extensions/extensions.

O procedimento é:

1. Navegue para https://github.com/laelgelc/cl_st1_gelc_llm_taggers
2. Clique no botão verde `<> Code` e escolha `Download ZIP`
3. Extraia o archive `cl_st1_gelc_llm_taggers-main.zip` em um local de sua preferência
4. Abra o VS Code. Clique `File` > `Open Folder` e selecione o diretório `cl_st1_gelc_llm_taggers-main`
5. Na área `Explorer` navegue para diretório `cl_st1_gelc_llm_tagger_en`, ou `cl_st1_gelc_llm_tagger_es`, ou `cl_st1_gelc_llm_tagger_ptbr`, conforme a língua (os sufixos indicam a língua: `en` = English, `es` = Spanish, e `ptbr` = Brazilian Portuguese)
6. O documento de tagset correspondente está no diretório `tagset`. É possível editar (alterar, copiar e colar, etc.) o documento no VS Code normalmente, sem que os tags IDs numéricos sejam omitidos
7. Enviem-me os tagsets revisados neste grupo de WhatsApp para que eu atualize o repositório

Para fechar o VS Code, clique em `File` > `Close Folder`, e, em seguida, `File` > `Exit`.

À medida que progredirmos, incluiremos os prompts de LLM e outros documentos, programas etc. (conhecidos, de maneira geral, como artefatos).
